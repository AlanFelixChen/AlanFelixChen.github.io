# 3-5年经验简历模板 · 使用说明

配套文件：[3-5年经验简历模板](/assets/doc/3-5-years-resume-template.html)

设计依据：《3-5年经验简历制作指南》

默认方向：嵌入式 Linux 应用开发（网络通信方向）——可自行替换文字用于其他岗位

---

## 一、这是什么

一份**单文件、可编辑、可导出**的 HTML 简历模板。双击用浏览器打开就能用，不需要安装任何软件，也不需要联网。

| 项目 | 说明 |
|---|---|
| 文件体积 | 约 46 KB（46,636 字节），单文件 |
| 依赖 | **零依赖**，无外部脚本、无外链字体 |
| 网络 | 完全离线可用 |
| 版式 | A4（210 × 297 mm），打印边距 14mm × 18mm |
| 可编辑范围 | 全部正文，点击即可输入 |
| 自动保存 | 本地浏览器存储，关掉再开内容还在 |
| 导出 | PDF / Word（.docx）/ 纯文本 |
| 代码规模 | 910 行，单文件封装 |

**核心设计**：模板内置「三档位」参数系统。你选一个档位，模板会自动调整项目结构、技能栈写法、经历条数、教育背景位置和篇幅上限，与《指南》第〇章的三档定位完全对应。

**三种版式**：经典单栏（默认，ATS 首选）/ 科技蓝（双栏）/ 简约极简，切换不影响已填内容。

## 二、环境要求

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge / Firefox 最新版（**推荐 Chrome**，导出与打印最稳定） |
| 操作系统 | Windows / macOS / Linux 均可 |
| 其他软件 | 无需安装 |
| 显示屏 | 建议电脑操作；手机能看能改，但打印导出体验较差 |

## 三、快速上手（5 步）

```
第1步  打开 3-5年经验简历模板.html
第2步  顶部「档位」下拉框，选最接近自己的档位
第3步  选版式（投递统一用「经典单栏」）
第4步  逐个点击【】占位处，替换成你的真实信息
第5步  「复制文本」做ATS自检 → 「下载 PDF」导出成品
```

## 四、界面总览

打开后页面顶部有一条**工具栏**（打印和导出时会自动隐藏，不会出现在成品里），分两行：

**第一行**
- `档位` 下拉框：切换下限档 / 中位档 / 上限档
- `版式` 三个按钮：经典单栏 / 科技蓝 / 简约极简

**第二行**
- 操作提示：`① 点击任意文字即可编辑；②【】为待填占位符；③ 填写内容自动保存到本地；④ 投递前用「复制文本」做ATS自检`
- 四个功能按钮：`下载 PDF`、`下载 Word`、`复制文本（ATS自检）`、`重置`

工具栏下方就是简历本体，一张模拟 A4 纸。**页面上所有灰色提示文字（模块标题旁的批注、右上角档位徽章、底部稳定性红线）都只用于编辑时提醒，打印和导出时会被自动隐藏，不会进入成品。**

## 五、档位选择（最关键的一步）

下拉框里有三个档位，参考《指南》第〇章的自测定位：

| 档位 | 适用年限 | 定位 | 篇幅上限 | 项目结构 | 技能栈 | 稳定性红线 |
|---|---|---|---|---|---|---|
| **下限档** | 3-4 年 | 站稳脚跟 | **1 页封顶** | 三段（背景→角色→产出） | 金字塔（基础扎实） | 跳槽 ≤ 2 次 |
| **中位档**（默认） | 4-5 年 | 独当一面 | **1-1.5 页** | 四段（背景+硬约束→职责→难点+方案→量化结果） | 过渡结构（金字塔+1-2方向深度） | 跳槽 ≤ 3 次，每份至少 1 年 |
| **上限档** | 接近 5 年 | 准备跃迁 | **最多 2 页** | 四段 + 协同架构 | T 型（1-2 纵深 + 周边广度） | 跳槽 ≤ 3 次，职业主轴清晰 |

**三档自测三问**（答"是"越多，档位越高）：

1. 能否**独立负责**一个完整模块或子系统，而不仅是完成任务？
2. 有没有**从 0 到 1** 参与或主导过项目/组件？
3. 有没有**带过新人**、或做过跨团队协同与架构决策？

**切档位时模板会自动变化的地方**：

- 工作经历条数：4+3+1 条（下限）/ 4+3+2 条（中位）/ 5+4+3 条（上限）
- 项目字段名：三段是「背景 / 角色 / 产出」，四段是「背景 / 职责 / 难点 / 结果」
- 项目数量：1 个（下限）/ 2 个（中档及以上）
- 技能栈写法：金字塔 / 过渡 / T 型三套文案自动切换
- 教育背景位置（经典单栏下）：**下限档自动前置**到个人简介下方；中位档、上限档放在工作经历之后
- 篇幅档位徽章：显示当前档位的页数上限

> ⚠️ **切换档位不会丢失已填内容。** 模板会先快照你填的每一项，重绘后自动回填（内部字段采用跨档位稳定的语义化定位，不会错位）。

## 六、版式选择

| 版式 | 风格 | 推荐场景 |
|---|---|---|
| **经典单栏**（默认） | 居中抬头 + 深蓝标题线，单栏通栏 | **网申、ATS 机器初筛**，兼容性最好 |
| 科技蓝 | 左侧深蓝侧栏 + 右侧白底主栏，双栏 | 技术岗邮箱直投，视觉辨识度高 |
| 简约极简 | 大量留白、弱化线条 | 打印纸质递送 |

**使用建议**：正式投递一律先用**经典单栏**导出 PDF。双栏版式在部分企业的简历解析系统里可能出现文字抓取顺序错乱，这是《指南》第二章强调过的坑。想给 HR 邮箱直投一份"好看版"时，再切到科技蓝另导一份。

> 切换版式同样**不会丢失已填内容**；从科技蓝切回其他版式时，模板会自动把双栏还原为单栏平铺结构。

### 6.1 科技蓝版式的模块分配

切到科技蓝后，简历内容会自动分成左右两栏，**模块归属是固定的**：

| 区域 | 背景 | 放置的模块 |
|---|---|---|
| **左侧栏** | 深蓝底、白字 | 姓名、联系方式、专业技能、证书与荣誉、教育背景 |
| **右侧主栏** | 白底、深字 | 求职意向、个人简介、工作经历、核心项目、稳定性提示 |

**要点**：
- **基础信息类**（联系方式、技能、证书、教育）在侧栏，**核心内容类**（意向、简介、经历、项目）在主栏——这与 HR 的阅读动线一致，先看人、再看能力。
- 与经典单栏不同，**科技蓝下教育背景固定放在侧栏**，不随档位前置/后置。
- 侧栏宽度 200px，联系方式较长时会自动换行，不必手动调。

## 七、填写指南

### 7.1 占位符与编辑规则

所有待填位置都用 **【】方括号**标出（如`【你的姓名】`、`【XX%】`、`【项目1名称】`）。

- 直接把括号连同里面的提示文字一起**选中替换**即可
- 不需要保留方括号
- 灰色字（如"项目是什么，要解决什么问题"）是提示，不是正文，替换掉即可

**粘贴规则**：模板对所有可编辑区域做了处理，**从网页或其他文档粘贴内容时，会自动转为纯文本**，不会带入原来的字体、字号、颜色，避免破坏版式。从别处搬内容过来可以放心直接粘。

### 7.2 建议填写顺序

```
① 姓名 + 联系方式 + 求职意向   ← 先定基调
② 专业技能                     ← 关键词密度最高，影响ATS
③ 最近一份工作经历             ← 优先填数字
④ 项目经历                     ← 技术岗真正的加分位
⑤ 更早的工作经历、教育背景
⑥ 个人简介（能力摘要）          ← 最后写，用前面提炼出的亮点
```

**为什么个人简介放最后写**：它的作用是把全文最亮的 1-2 个成果浓缩成 3 句话，等经历都填完了再写，比一开始硬憋准确得多。

### 7.3 各模块写法要点

**个人简介 / 能力摘要**
- 定位是「HR 第三个阅读位，决定要不要继续往下翻」，务必写好
- 2-4 句、120 字以内
- 公式：`年限 + 核心技能栈 + 代表性成果 + 成长性/独特价值`
- 模板已按档位预置三套示例文案，直接改数字和方向即可

**专业技能**
- 按四层分类填写：语言与数据结构 / 硬件接口与架构 / 操作系统与中间件 / 工程化与调试工具
- **下限档和中位档不要写"精通"**，用"熟练掌握""深入理解"替代；上限档才可适度使用"精通"
- 技能栏是 ATS 关键词的主要来源，务必把你真实用过的协议、平台、工具都写进去

**工作经历**
- 每条要点以**强动词**开头：主导 / 独立负责 / 搭建 / 优化 / 推动（避免"参与""协助"）
- 量化数据放在**每条要点开头**，最亮的业绩排第一条
- 写不出数字时，用「改造前 → 改造后」的对比写法替代（如"由人工排查改为日志自动定位"）

**项目经历**
- 按当前档位对应的字段结构填写，不要写"参与"
- 技术岗重点写清：背景的硬约束（成本/功耗/实时性/资源受限）、具体难点、你的方案选择、量化结果

**教育背景**
- 只写「学校 + 专业 + 学历 + 时间」
- 名校、对口专业可加粗

**联系方式栏的 GitHub 位（技术岗重点）**
- 联系方式栏中预留了 `GitHub：【链接】` 的位置，**技术岗建议务必填写**
- 这是《指南》第四章强调过的"硬实力凭证"——有开源项目、技术博客的，把链接放上去，比口头描述有说服力
- 没有 GitHub 的可以不填或替换成技术博客、个人主页链接；**不要填无关链接**（如朋友圈、微博）

### 7.4 篇幅控制

- 下限档填完**必须压到 1 页**；填不下就删次要经历，不要缩字号
- 中位档 1-1.5 页；上限档最多 2 页
- 早期经历（5 年前）压到 1-2 行，不相关的直接删掉

## 八、导出与投递

### 8.1 下载 PDF（投递主用）

点击「下载 PDF」后，浏览器会弹出打印对话框，请设置：

| 选项 | 设置 |
|---|---|
| 目标打印机 | **另存为 PDF / Save as PDF** |
| 纸张大小 | **A4** |
| 边距 | **默认** |
| 页眉和页脚 | **取消勾选** |
| 背景图形 | 建议勾选（保证标题线等元素显示） |

> 模板已声明 A4 页面尺寸，正常情况下打印对话框会默认选中 A4。若你的浏览器默认纸张是 Letter，请手动改为 A4，否则长宽比例会偏。

**文件名规范**：导出后手动重命名为 `姓名_岗位_年限.pdf`（如 `张伟_嵌入式Linux开发_5年.pdf`）。不要用"个人简历.pdf"这种名字。

### 8.2 下载 Word（备用）

点击「下载 Word」会生成一个真正的 `.docx` 文件（不是网页改后缀）。

- 文件名自动取简历里填的姓名，如 `张伟.docx`；没填姓名则为 `简历.docx`
- 导出内容与网页一致，且**不含任何编辑提示、徽章、稳定性红线**（与 PDF 同样干净）
- 用途：部分老式招聘系统只接受 Word 格式，作为备用
- **注意**：Word 在不同电脑上打开可能有排版偏移，正式投递优先用 PDF，只在对方明确要求 .docx 时提交 Word

### 8.3 复制文本（ATS 自检）

点击「复制文本（ATS自检）」，页面会把正文提取为纯文本放进剪贴板（已自动剥离所有编辑提示与徽章，不会污染）。

弹出提示后，按三步自检：

1. 粘贴到记事本 / 纯文本编辑器，检查**文字是否完整、有无乱码**
2. 检查**顺序是否正确**：姓名 → 意向 → 简介 → 经历 → 项目 → 教育 → 技能
3. 检查**岗位关键词**（socket / epoll / MQTT / 多线程 / 驱动 等）是否自然出现

> 如果纯文本里都是乱的，说明机器也就读到乱的——投递前务必修正版式。

## 九、自动保存与重置

**自动保存**
- 每次输入停止 **1.5 秒**后自动存入浏览器本地存储
- 关闭页面前也会强制保存一次
- 下次用**同一个浏览器**、**同一个文件位置**打开，内容自动恢复（档位、版式、正文都会恢复）

**重置**
- 点击工具栏「重置」，确认后会清空本地保存，恢复到初始模板（档位回到中位档、版式回到经典单栏）
- 重置不可撤销，操作前请确认

**注意**：自动保存依赖浏览器本地存储，以下情况内容不会恢复——换浏览器、换电脑、清理浏览器数据、用无痕模式、以 file:// 之外的方式打开时域名/路径变化。

## 十、投递前检查清单

**A 组 · 机器可读性**
- [ ] 「复制文本」输出的纯文本完整、无乱码、顺序正确
- [ ] 岗位关键词（协议、平台、工具名）自然出现
- [ ] 硬性门槛信息齐全（学历、年限、目标岗位）

**B 组 · 人眼观感**
- [ ] 导出前的档位与目标岗位匹配，篇幅不超上限
- [ ] 版式为经典单栏，无错行、无溢出
- [ ] 排版统一，无忽大忽小的字号
- [ ] 无错别字、无多余空格、无残留的【】符号

**C 组 · 内容质量**
- [ ] 每条经历都有量化数据或「改造前→改造后」对比
- [ ] 最近一份经历最详细，早期经历已精简
- [ ] 没有"精通"滥用（中低档位）
- [ ] 时间线连贯，无无法解释的空窗期
- [ ] 简历上写的每条经历，面试都能展开讲三层

## 十一、常见问题

**Q1：切换档位后，我填的内容会消失吗？**
不会。模板会先保存你填的每一项，重绘后自动回填。档位、版式切换都不丢内容，也不会出现内容错位到别的字段。

**Q2：导出的 PDF / Word 里会不会看到"HR第3个阅读位"这类提示？**
不会。所有编辑提示、档位徽章、稳定性红线都已设置打印隐藏，导出成品干净。如果仍有残留，请用最新版本的模板文件重新导出。

**Q3：为什么我的 PDF 是两页，明明只填了一点？**
检查档位。下限档必须压到 1 页；中位档允许 1-1.5 页；上限档最多 2 页。若内容确实少却排版溢出，可适当精简条目。

**Q4：Word 导出后排版和网页不一样？**
正常现象。Word 的渲染引擎与浏览器不同，可能有轻微偏移。**正式投递一律用 PDF**。

**Q5：内容保存到哪了？会不会上传到网上？**
保存在你自己浏览器的本地存储里，**不上传、不联网**。换设备或清理浏览器数据会丢失。

**Q6：我不是嵌入式方向的，能用吗？**
能。模板里的技能分类和示例文案是通用结构，把"嵌入式Linux、socket、epoll"等换成你所在方向的术语即可。

**Q7：怎么实现"先写 2 页素材库，再精炼成 1 页"？**
先用**上限档**把所有经历尽量填全（素材库状态），再切回你实际应属的档位，按提示删减精简到目标篇幅。

**Q8：科技蓝版式下内容跑版怎么办？**
请使用最新版模板文件。早期版本的双栏结构未真正生成，会出现内容横向挤压。最新版已修复，切到科技蓝会自动生成"深蓝侧栏 + 白底主栏"的双栏结构。

**Q9：从网上复制内容粘进来，格式乱了？**
模板已自动处理，粘贴时会转为纯文本，不会带入原格式。如果发现异常，请确认使用的是最新版模板。
